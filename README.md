# kinō — 3D-комната команды

Полноэкранная интерактивная сцена на Three.js / WebGL 2. Все постоянные объекты зала — настоящие объёмные meshes: платформа, экран с рамой и опорами, кукольные персонажи, кубы и высокие стикеры. Перспективная камера по умолчанию смотрит сверху под углом 53°. Нет постоянной шапки и боковой панели; инструменты находятся на плавающем острове.

## Управление

- WASD / стрелки — движение относительно камеры; работает независимо от раскладки клавиатуры.
- Space — прыжок. Повторный прыжок в воздухе запрещён.
- Левый клик — бросок снежка в точку под курсором в активном режиме снежков (по умолчанию). Попадания определяются по треугольникам реальных 3D-моделей; шар летит по баллистической траектории.
- E — пнуть ближайший маленький куб. Столкновение при ходьбе также толкает его.
- V — взаимодействие: нажать объект для действий, потянуть стикер или куб для перемещения.
- Правая кнопка — действия с выбранным объектом в любом режиме.
- N — поставить стикер следующим кликом; C — поставить маленький куб; X / Escape — вернуться к снежкам.
- Колесо — масштаб; средняя кнопка и движение — поворот/наклон камеры. Настройки ракурса доступны также на панели.

## Персонажи и физика

Кукольная геометрия: крупная округло-кубическая голова, большие объёмные глаза с бликами, маленькие губы, маленькое тело, руки и ноги, объёмные причёски и аксессуары. Настраиваются имя, цвет одежды, кожа, волосы и аксессуары. Все персонажи поворачиваются к курсору. Любого демонстрационного персонажа можно выбрать для управления.

Один большой куб высотой 1.65 единицы: боковые коллизии, поддержка сверху, прыжок на куб и падение с края. Действие «Забраться» подходит к кубу и выполняет реальный прыжок. При переносе куба стоящий на нём персонаж и установленные стикеры перемещаются вместе с опорой.

Маленькие кубики имеют скорость, вертикальный подскок, отскок от границ и объектов, затухание движения и передачу импульса при столкновениях. Их можно пинать, тянуть и убирать. Симуляция работает с фиксированным шагом 1/120 секунды.

## Ретро и экран

Стикеры — высокие объёмные панели на подставках, с текстом на текстуре лицевой поверхности. Можно перетаскивать по полу и ставить на большой куб, редактировать, удалять, голосовать. Доска открывается по требованию и поддерживает перенос между тремя категориями. Данные мигрируют из предыдущей версии. Есть таймер, реакции, экспорт JSON.

Киноэкран — 3D-объект. Портреты на нём рендерятся из тех же объёмных моделей персонажей через WebGLRenderTarget. Камера и показ экрана используют VideoTexture. Можно закрепить плитку или вернуть всех. Медиа требуют HTTPS и разрешений браузера.

## Границы

Это локальный прототип: удалённых участников, WebRTC SFU/TURN и серверной синхронизации пока нет. Демонстрационные персонажи не являются подключёнными людьми. Видео, микрофон и экран не передаются другим пользователям. Стикеры, кубики и внешность основного персонажа сохраняются в localStorage. В интерфейсе эти ограничения описаны в справке и меню комнаты.

## Код

- `dist/app.js`: сцена, текстуры, интерфейс, взаимодействия, input, медиа.
- `dist/avatars.js`: объёмные персонажи и общий кэш геометрии/материалов.
- `dist/physics.js`: детерминированная физика.
- `dist/vendor/`: Three.js 0.180.0 и RoundedBoxGeometry (MIT, лицензия включена).
- `tests/physics.test.mjs`: тесты прыжков, коллизий, опор, отскоков и импульсов.
- `tests/scene.test.mjs`: интеграционные тесты с настоящими Three.js meshes и raycasting. GPU renderer замокан, DOM предоставляется jsdom.

Сайт статический, сборка для публикации не требуется; runtime-зависимости включены локально. Установка для разработки: `npm ci`. Проверка: `npm run check`.

## Проверка этой версии

Автоматически проверены создание сцены, WASD, Space, первый клик-снежок, поворот персонажей к курсору, подъём на большой куб, выбор плитки по пересечению настоящих треугольников, редактор стикеров, drag-and-drop 3D-панели и кубика, сохранение данных, а также физические сценарии.

В управляемом тестовом браузере WebGL отключён (GL_RENDERER=Disabled). Поэтому графический вывод и аппаратные медиоустройства в этой среде НЕ проверены. Пользователю нужен браузер с WebGL 2. Никакой 2D-подмены сцены не используется.
